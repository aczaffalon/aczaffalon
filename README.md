## 🚀 Projeto em destaque

### Rota Certa Pro

Aplicação mobile-first criada para cálculo, registro e acompanhamento de rotas de entregadores.

O projeto nasceu de uma necessidade real no trabalho com entregas e está evoluindo para incluir controle de custos do veículo, rentabilidade por rota e análise financeira da operação.

**Principais recursos:**
- cálculo de rotas;
- histórico de entregas;
- fechamentos diário, semanal, quinzenal e mensal;
- exportação em PDF e CSV;
- backup local;
- configurações personalizadas;
- módulo de veículo;
- evolução para controle de custos e rentabilidade.

**Tecnologias:**
React, TypeScript, Vite, Tailwind CSS, Capacitor e jsPDF.

🔗 [Ver projeto Rota Certa Pro](https://github.com/aczaffalon/rotaCertaPro)
